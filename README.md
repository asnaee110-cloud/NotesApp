# NotesApp 📝

A simple and responsive Notes Application built using React.

## About the Project
NotesApp is a web application that helps users create, manage, search, and organize their notes easily.

## Features
- Create new notes
- Edit existing notes
- Delete notes
- Search notes
- Responsive user interface

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## Project Structure
- App.jsx
- Header.jsx
- ColorPicker.jsx
- NoteCard.jsx
- NoteCreation.jsx
- NoteList.jsx
- SearchBar.jsx

## Getting Started
1. Clone this repository.
2. Install dependencies using `npm install`.
3. Start the development server using `npm run dev`.
